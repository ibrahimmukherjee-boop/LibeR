Quick start

1. Open the Data tab and load the example study (or import a CSV with ID, TIME, EVID, AMT, DV columns).

2. Adjust the model in Code or Visual model.

3. Press Estimate in the workflow rail, then Diagnostics for GOF plots and Uncertainty for bootstrap standard errors.

ADVAN routes

ADVAN1 — one-compartment IV bolus. ADVAN2 — one-compartment first-order absorption. THETA(1)=CL, THETA(2)=V, THETA(3)=ka.

About this concept

Estimation here is Nelder–Mead least squares on log concentrations with a −2LL report. The production engine (FOCE/SAEM/Bayesian, ODE/DDE solvers, exact AD) lives in the R packages.
