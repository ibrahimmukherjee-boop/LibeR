What is this? A redesign concept of the LibeRation workbench following the LibeR Mono philosophy: monochrome, guided, large type, one clear next action. The pharmacokinetic simulator and least-squares fitter below run entirely in your browser; the production engine (FOCE/SAEM/Bayesian estimation, ODE solvers, exact automatic differentiation) lives in the R packages.
